Now we have a clear definition of a Parley template for use in Agencia.
I want you to implement that template feature for Parley.
I also want you to allow the Go templates to be used if the first line is a comment:
//Use Go
This means to use the standard Go templates.  This is for test cases and debugging.

The file docs/parley_dart.md is a good starting point for implementing Parley.
This document will give you more details for each form:


INPUT             // exactly what the user entered
INPUT <label>     // a specific destructured input

// SEND delivers a message or a list to another agent. Optional IN points to a library.
SEND <label> MESSAGE <value>
SEND <label> MESSAGE ... END
SEND <label> IN <label> MESSAGE <value>
SEND <label> LIST <value>
SEND <label> LIST ... END
SEND <label> IN <label> LIST <value>

FACT <label> IN <label>
FACT <label>

IF <predicate> THEN <value> ELSE <value>   // statement form does not need END
IF <predicate> THEN ... END
ELSE IF <predicate> THEN ... END
ELSE ... END

// LIST reads and writes bullet lists by default. FROM adjusts the reader format; AS controls output.
LIST <value>
LIST <value> FROM BULLETS
LIST <value> FROM LINES
LIST <value> FROM PARAGRAPHS
LIST <value> AS BULLETS
LIST <value> AS LINES
LIST <value> AS PARAGRAPHS

LET <label> BE <value>
LET <label> BE ... END

USE <label>
